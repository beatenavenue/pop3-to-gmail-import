# プライバシーポリシー

これは [PRIVACY.md](PRIVACY.md) の日本語版です。内容が食い違っている場合は英語版を正とします。Google Cloud コンソールに登録されているのは英語版の URL です。

pop3-to-gmail-import はホスティングされたサービスではありません。各利用者が自分の端末で、自分の Google Cloud プロジェクトと自分の OAuth クライアントを使って動かすソースコードです。共用のインスタンスを運用している者は誰もいません。

そのため、通常のプライバシーポリシーという形式はこのソフトウェアには馴染みません。この文書が存在するのは、OAuth アプリを公開するために Google Cloud コンソールがプライバシーポリシーの URL を要求するからであり、また自分のコピーを公開する人が、何について責任を負うことになるのかを知る必要があるからです。

## この文書の対象

このポリシーは、このリポジトリにある無改変のソースコードについて、その作者が公開したままの状態を記述しています。

個々のデプロイについて記述したものではありません。このコードのコピーを動かす人が、それが何をするか、どこで動くか、扱ったメールがどうなるかを決めます。改変されたコピーは、以下に記述したすべての点について異なる振る舞いをしうります。

## 自分のコピーを動かす場合

あなたのデプロイの運用者はあなたであり、このリポジトリの作者ではありません。作者はそれに対するアクセス手段を持たず、その存在を知らず、責任も負いません。

この文書を自分の OAuth アプリのプライバシーポリシーとして提出しないでください。自分のデプロイが実際に何をするのかを記述した、自分のポリシーを書いてください。この文書を流用すると、自分のデプロイについて誤った記述をすることになり、かつ利用者を、それについて答えられない人物に差し向けることになります。

## コードが Google のユーザーデータに対して行うこと

- OAuth スコープは `https://www.googleapis.com/auth/gmail.insert` の 1 つだけを要求します。このスコープはメールボックスへのメッセージ追加を許可します。アカウントに既にあるメッセージの読み取り、変更、削除は許可しません。
- そのスコープを使う目的は 1 つで、`users.messages.import` を呼び出し、POP3 メールボックスから取得したメールを、アクセスを許可した Gmail アカウントに入れることです。
- それ以外のどこにもデータを送りません。アナリティクスもテレメトリもなく、作者や第三者への報告もありません。

Google API から受け取った情報の利用は、Limited Use の要件を含む [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy) に従います。

## 資格情報

POP3 の資格情報、OAuth クライアントシークレット、OAuth リフレッシュトークンは、コードが動く端末上で運用者が保持します。コードはこれらを、POP3 サーバと Google 以外のどこにも送信しません。

アクセスは [Google アカウントのアクセス権](https://myaccount.google.com/permissions) からいつでも取り消せます。
